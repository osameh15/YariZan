## Refinement pass

The save, left-arrow and minus icons were regenerated using the home icon as style reference. Prompt: create the named icon with a simple solid teal shape and small ochre detail, square transparent canvas at 70 percent scale, crisp clean alpha edges and empty internal space; no glow, haze, shadow, blur, texture, gradient, backdrop, lettering or extra objects. The final save icon is a disk outline; the arrow points left; the minus is a single horizontal bar. All icons are encoded as 128×128 WebP with alpha, about 142 KB for the whole family. Labels, receipts, chart graphics, math expressions and official brand/trust logos keep their meaning and remain separate from decorative interface icons.

## RTL direction

The source arrow points left. Logical Back/Previous variants rotate it 180 degrees to point right for Persian RTL navigation. Forward/Next variants point left. External and vertical actions use their own explicit rotations; mathematical text and charts are not mirrored. The earlier glowing arrow is discarded.
